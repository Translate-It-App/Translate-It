افزونه **Translate It** فراتر از یک مترجم است؛ اکوسیستمی ماژولار برای ترجمه با فلسفهٔ «بدون فشار» است. این افزونه برای مرور روزمره سبک می‌ماند و ترجمهٔ متن، صفحه، سند، تصویر، زیرنویس و صدای زنده را در یک ابزار، روی دسکتاپ، دستگاه‌های لمسی و موبایل فراهم می‌کند.

افزونه Translate It با پشتیبانی از **بیش از ۱۰ سرویس ترجمه**، بر حریم خصوصی، انعطاف‌پذیری، کارایی و اختیار شما در انتخاب شیوه و محل پردازش ترجمه‌ها تمرکز دارد.

## هدف

- **حریم خصوصی و کنترل:** شیوهٔ پردازش ترجمه‌ها را انتخاب کنید؛ از جمله سرویس‌های محلی، آفلاین، رایگان و ابری، هرجا که پشتیبانی شوند.
- **آزادی انتخاب:** بدون وابستگی به یک سرویس، میان ارائه‌دهندگان ترجمهٔ سنتی و مبتنی بر هوش مصنوعی جابه‌جا شوید.
- **یک ابزار برای نیازهای گوناگون:** متن انتخاب‌شده، فیلدهای ورودی، عناصر صفحه، کل صفحات، PDF، زیرنویس، متن تصاویر با OCR، متن زیر نشانگر ماوس و صدای زنده را ترجمه کنید.
- **مناسب مرور روزمره:** برای صفحات پویا، محتوای طولانی، ترجمهٔ پیوسته و استفاده روی دسکتاپ، دستگاه‌های لمسی و موبایل طراحی شده است.

## قابلیت‌ها در یک نگاه

| قابلیت | توضیحات |
| :--- | :--- |
| **انتخاب متن** | متن انتخاب‌شده را بی‌درنگ و بدون خروج از صفحه ترجمه کنید. |
| **انتخاب عنصر** | عناصر مشخص صفحه را درجا و با حفظ چیدمان اطراف ترجمه کنید. |
| **ترجمهٔ کل صفحه** | تمام صفحه‌ها، از جمله محتوای بارگذاری‌شده در ادامه، پیوسته ترجمه می‌شوند. |
| **پنجرهٔ بازشو و پنل کناری** | متن را مستقیماً از پنجرهٔ افزونه یا پنل کناریِ همیشه‌در‌دسترس ترجمه کنید. |
| **Live Dubbing** | صدای زبانهٔ فعال را با Gemini یا OpenAI به‌صورت زنده ترجمه کنید. **فقط در Chrome.** |
| **مترجم PDF** | فایل‌های PDF محلی و آنلاین را با نمایش دوزبانه، OCR و امکان خروجی گرفتن ترجمه کنید. |
| **مترجم زیرنویس (SRT)** | فایل‌های زیرنویس `.srt` را با حفظ زمان‌بندی و قالب‌بندی ترجمه کنید. |
| **عکس‌برداری از صفحه و OCR** | متن تصاویر، ویدیوها، PDFها و محتوای دیگری را که نمی‌توان انتخاب کرد، ثبت و ترجمه کنید. |
| **ترجمه با نشانگر ماوس** | واژه‌ها، جمله‌ها یا بلوک‌های متن را مستقیماً هنگام قرار گرفتن نشانگر روی آن‌ها ترجمه کنید. |
| **FAB دسکتاپ و موبایل** | با دکمهٔ شناور و قابل‌جابه‌جایی، سریع به ابزارهای ترجمه دسترسی پیدا کنید. |
| **ترجمه در فیلد (Ctrl+/)** | پیش از ارسال، متن را مستقیماً در فیلدهای قابل ویرایش ترجمه کنید. |
| **واژه‌نامه و TTS** | معنی واژه‌ها را پیدا کنید و به متن اصلی یا ترجمه‌شده گوش دهید. |
| **تاریخچه و خروجی** | تاریخچهٔ ترجمه‌ها را نگه دارید و برای استفادهٔ بعدی خروجی بگیرید. |

## سرویس‌های پشتیبانی‌شده

از میان سرویس‌های ترجمهٔ سنتی، مبتنی بر هوش مصنوعی، محلی و تخصصی انتخاب کنید:

- **سنتی:** [Google Translate](https://translate.google.com/)، [Microsoft Edge Translator](https://www.microsoft.com/translator/)، [DeepL](https://www.deepl.com/translator)، [Yandex](https://translate.yandex.com/)، [Lingva](https://github.com/TheDavidDelta/lingva-translate)، [Bing](https://www.bing.com/translator)
- **هوش مصنوعی:** [Gemini](https://ai.google.dev/)، [OpenAI](https://openai.com/api/)، [OpenRouter](https://openrouter.ai/)، [Requesty](https://www.requesty.ai/)، [DeepSeek](https://platform.deepseek.com/)
- **سفارشی و محلی:** OpenAI-Compatible APIs، [WebAI-to-API](https://github.com/Amm1rr/WebAI-to-API/)، Browser Translation
- **واژه‌نامه:** [Vajehyab](https://vajehyab.com/)

برخی سرویس‌ها به کلید API نیاز دارند و برخی دیگر بدون آن کار می‌کنند.

**Live Dubbing** در حال حاضر با Gemini و OpenAI در Chrome کار می‌کند.

## قابلیت‌های کلیدی

### ۱. ترجمهٔ تدریجی
ترجمه‌های طولانی به بخش‌های کوچک‌تر تقسیم می‌شوند و نتیجه‌ها به‌تدریج و هم‌زمان با آماده شدن نمایش داده می‌شوند.

### ۲. انتخاب عنصر
بخش‌های مشخصی از صفحه را درجا و با حفظ چیدمان اطراف ترجمه کنید و در صورت نیاز محتوای اصلی را بازگردانید.

### ۳. ترجمهٔ کل صفحه
با ظاهر شدن محتوای جدید، صفحه را پیوسته ترجمه کنید. حالت‌های Fluid و Translate-on-Scroll-Stop برای نیازهای گوناگون مرور و کارایی در دسترس‌اند.

### ۴. Live Dubbing
صدای زبانهٔ فعال را با Gemini یا OpenAI به‌صورت زنده ترجمه کنید و صدای اصلی و دوبله‌شده را جداگانه کنترل کنید. **فقط در Chrome.**

### ۵. مترجم PDF
فایل‌های PDF محلی یا آنلاین را با نمایش دوزبانه، انتخاب متن، OCR برای اسناد اسکن‌شده و خروجی TXT، Markdown یا HTML ترجمه کنید.

### ۶. عکس‌برداری از صفحه و OCR
از هر بخش صفحه عکس بگیرید و متن تصاویر، ویدیوها، PDFها یا محتوای غیرقابل‌انتخاب را با OCR محلی ترجمه کنید.

### ۷. مترجم زیرنویس (SRT)
فایل‌های زیرنویس را با حفظ زمان‌بندی و قالب‌بندی ترجمه کنید و روند ترجمه را ببینید.

### ۸. تجربهٔ دسکتاپ، لمسی و موبایل
از کنترل‌های FAB قابل‌جابه‌جایی و رابط‌های بهینه‌شده برای لمس روی دسکتاپ، دستگاه‌های لمسی و مرورگرهای موبایل پشتیبانی‌شده استفاده کنید.

### ۹. ترجمه با نشانگر ماوس
واژه، جمله یا بلوک متن را هنگام مرور و بدون باز کردن ابزار ترجمه‌ای جداگانه ترجمه کنید.
