# Firefox page-translation capability probe

Run with `pnpm exec node scripts/dev/page-translation-e2e-firefox/run.mjs`; focused tests use `pnpm test:run scripts/dev/page-translation-e2e-firefox.test.js`. The probe re-execs itself in a rootless network namespace and verifies exactly loopback-only addressing with no IPv4 or IPv6 routes before running Firefox or reading browser version. It uses Firefox's announced WebDriver BiDi websocket directly; no geckodriver or automation framework is involved.

The probe subscribes to BiDi request events before registering interception. It continues only loopback fixture traffic, provides the known empty startup voice list, fails every other intercepted HTTP(S) request, then closes request admission and drains handlers before teardown. It checks actual fixture DOM text plus bounded `script.getRealms`/`script.evaluate` observations for the instrumented worker/content entries, readiness, and exact `{ slicedDiscoveryEnabled: true, viewportFirstDiscoveryEnabled: false }` flags. No Firefox extension system-access override is enabled; installation metadata is not treated as execution readiness. Background/content dependent probes remain `NOT_TESTED` when those real contexts cannot be inspected.

Real Edge request-body/response handling and the held-request abort/settlement/stale-delivery lifecycle are explicitly **not implemented** in this bounded probe; those capabilities remain `NOT_TESTED` even if runtime realms become inspectable. Background/content negative fetches are attempted only when both real realms, readiness, and exact discovery flags pass. The probe does not claim that those deferred scenarios run automatically when a gate becomes available.

An atomic JSON artifact is written to `/tmp/opencode/page-translation-firefox-<run-id>.json` by default. Set `FIREFOX_PROBE_ARTIFACT` to choose its path (the parent directory must already exist). If that path already exists, a run-ID-suffixed path is used so prior artifact bytes are preserved. Results use `SUPPORTED`, `UNSUPPORTED`, `FAILED`, and `NOT_TESTED`. Exit status: 0 only when every required capability is `SUPPORTED`; 2 when a capability is unsupported or gated/not tested; 1 for failure, timeout, protocol, cleanup, or artifact errors. Artifacts include a unique run ID, HEAD and source hashes, runtime versions, commands/events/request outcomes, network-scope evidence, and limitations. This is a bounded capability probe, not the full Firefox E2E suite or 1000-target matrix.
